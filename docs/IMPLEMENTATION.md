# Pixel AFM implementation and source mapping

This implements only the single-call, teacher-free baseline authorized on October 1, 2026. The original starter and AFM snapshot remain protected. `afm_fastgen/common.py:verify_protected` checks the original hashes, the exact base `Model` AST source, the partition and every vendored AFM file.

| Component | Source and adaptation |
|---|---|
| Generator | `soflow_fastgen/unet.py` at local SoFlow commit `3841b79044b0c64c1af4e2ea925e2068f681b767`, copied into `afm_fastgen/unet.py`. NVIDIA CC BY-NC-SA attribution and license retained in `licenses/`. Song U-Net128, two residual blocks/resolution, multipliers 1/2/2/2, attention at 16 and bottleneck 8, [1,3,3,1] resampling. The endpoint predicts pixels directly; time embeddings, consistency preconditioning, transform conditioning and all dropout are removed. Class mapping and two embedding layers remain. No learned module follows the U-Net. |
| Discriminator | New residual convolutional scalar critic: 64/128/256/512 channels, four downsampling blocks, one 512-channel block at 4×4, global spatial mean and class projection. No batch-dependent statistics, spectral normalization, time/source-noise conditioning, pretrained features or auxiliary head. Kaiming initialization and small class embeddings. A moderate convolutional critic is appropriate for 64×64 and keeps the simultaneous workload tractable. |
| G objective | AFM `train_adversarial_flow_imagenet.py:training_step`: mean softplus(real logit − fake logit) + λOT mean((G(z,c) − z)²). Source is Gaussian image-shaped noise, not an unrelated real target. At s=1,t=0 the time weight is 1. |
| D objective | Mean softplus(fake − real), finite-difference R1 and R2 with independent Gaussian perturbations after augmentation, and λCP mean((real + fake)²). Both compared logits receive parameter gradients. G is detached on D steps. D parameters are frozen on G steps, retaining input gradients. |
| Gradient normalization | Port of MIT-licensed `grad_norm.py`, same FP32 state/update/formula at accumulation=1. For accumulation, the running square tracks each **unweighted local-mean** adversarial backward; the outgoing gradient retains microbatch weight m/B. This deliberately fixes upstream accumulation's cancellation of that weight. State updates once per G microbatch backward, so microbatch size/order remains part of the frozen recipe. This is not ordinary gradient clipping and does not promise equivalence across microbatch sizes. |
| Accumulation/GP | Effective batch fixed; uneven final chunks weighted by actual m/B. Exactly max(1,round(B×.25)) random GP samples per D update across the whole batch; penalty chunks weighted by their GP count/global count. This avoids rounding each chunk and changing regularization exposure. |
| Schedules | AFM cosine equation/end behavior reimplemented without OmegaConf; schedule index is completed **G updates**, starting at zero. Each cycle performs one D optimizer step then one G optimizer step and one EMA update. No schedule advances per microbatch. |
| Augmentation | Inspected starter examples: predominantly upright, distinctive colors, varied poses and artwork/photos. Real x-flip p=.5; paired D translations up to ±8px p=.5 and one 16×16 cutout p=.5, white fill, same random transform on matched real/fake. Less severe than the optional upstream ±30% / three erasures. No color changes or rotations that could damage class cues. OT uses unaugmented pixels. |
| Data | Fixed copied partition only. Custom read-only wrapper reproduces official PIL RGB, torchvision bilinear 64×64 resize and normalization. A lossless uint8 optimization cache under AFM avoids repeatedly decoding shared inputs. Two independent shuffled streams have saved permutation, generator RNG, cursor, epochs and presentation counts; no loader-prefetch cursor ambiguity. No downloader or partition writer is called. |
| Precision/dependencies | FP32 throughout, including finite differences and gradient normalization, deterministic cuDNN, no TF32, AMP or BF16. Separate `fastgen_afm` environment; official supplied top-level dependencies only, with torch 2.7.1+cu126 / torchvision .22.1+cu126. No Kornia, timm, VAE, Lightning or upstream requirements bulk install. |
| Evaluation/export | Original `evaluate.py` functions prepare PNG references, generate 20 images/class and compute clean FID. The data module adapter points exclusively to development images. Export contains EMA G state only and loads via the untouched base loader in an independent directory. Clamp is arithmetic after exactly one G call. Few-NFE is intentionally unimplemented. |

Clean-FID 0.1.35 hardcodes `/tmp` for its Inception weights. The evaluator redirects only the `InceptionV3W` constructor's cache argument into `artifacts/cache/clean-fid`, preserving the original feature model, preprocessing, PNG conversion and FID computation. It records the extractor weight hash. The initial smoke was deliberately interrupted when this storage issue was found; its cost and generated files are retained. No dependency or protected source is patched.

Method reference: [Adversarial Flow Models](https://arxiv.org/html/2511.22475v2), equations 1–14 and 23. The paper's ImageNet latent-space results do not establish a suitable horizon or expected Pokémon FID. All recipe values and cost limits will be frozen after disposable qualification.
