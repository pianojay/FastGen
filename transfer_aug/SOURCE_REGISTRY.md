## Verification level

- Read primary papers and selected upstream source/configuration files. Downloaded files were not imported or executed; no checkpoints were retrieved.
- AdaIN sequential layers and WCT convolution declarations were counted through Python syntax trees. Other totals use explicit layer arithmetic transcribed from the pinned architectures. Biases, affine normalization, style-modulation MLPs, patch discriminators, and StarGAN EMA copies are included in their stated scopes.
- The main report identifies missing paper details and adaptations. No runtime, GPU-memory, correctness, or image-quality claim is implied by an arithmetic count.
- Cached PDFs have local URL/hash metadata under `audit_sources/papers/`. These caches are not versioned; the paper links above are the durable references.

## Reproduce static counts

From `/home/user/jw_soflow/exploration`, using the existing environment:

```bash
.conda/eda/bin/python transfer_aug/restore_audit_sources.py
.conda/eda/bin/python transfer_aug/count_audit_parameters.py
```

The first command requires network access only for missing source files. It restores files at pinned revisions and verifies SHA-256 hashes. It does not download datasets, papers, model weights, or install dependencies. The second performs source parsing and integer arithmetic only. Original discovery scripts `fetch_audit_sources.py` and `fetch_audit_details.py` document the initial search but can resolve newer default branches; use the restore script for this pinned audit.
